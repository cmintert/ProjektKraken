# ProjektKraken 0.20.0 beta 1

Windows x64 beta. This version improves authoring workflows,
unfinished-work protection and data recovery since 0.19.7-beta1, and adds
offline contextual Help.

## Changes since 0.19.7-beta1

- Entity and Event inspectors group writing, Connections, Details and Media.
  Writing controls and link actions have visible routes, and Connections support
  inline capture and refinement.
- Map editing protects unfinished geometry and journeys. Contextual creation,
  selection and drag gestures preserve the originating authoring context.
- Timeline presentation distinguishes uncertain occurrence, duration and viewed
  time. Event navigation and save feedback are clearer.
- F1 opens contextual offline Help. Search the manual or use Shift+F1 to explain
  supported controls under the pointer.
- World upgrades use versioned migrations and recovery bundles. Backup, restore,
  export and undo handling have stronger persistence safeguards.
- Diagnostics retain failure evidence while keeping authored content out of
  ordinary logs. Startup load failures release the splash and show the error.
- Temporal editing, timeline layout, relations and spell checking have clearer
  responsibility boundaries and additional regression coverage.

The repository
[changelog](https://github.com/cmintert/ProjektKraken/blob/main/CHANGELOG.md)
contains the detailed history.

## Install and verify

Download
`ProjektKraken-0.20.0-beta1-windows-x64.zip` and its matching `.zip.sha256` file.
In PowerShell, run:

```powershell
Get-FileHash .\ProjektKraken-0.20.0-beta1-windows-x64.zip -Algorithm SHA256
```

Compare the reported hash with the value in the `.sha256` file. Extract the
complete ZIP into a normal user folder, then run
`ProjektKraken\ProjektKraken.exe`. Keep `_internal` beside the executable.
The application is unsigned; Windows may ask you to confirm that you want to
run it.

For an update, keep a backup of your complete world folders and install the
complete new application folder. Do not replace only the executable. World
upgrades can change the database schema; retain the backup for use with an older
application version.

## Known limitations

- Windows x64 is the packaged platform for this beta.
- Relation vocabulary and forward/reverse wording remain follow-up work.
- Tab navigation between workspaces and writing editors is still being refined.
- Rich wiki editing supports paragraphs, headings 1–3, bold, italic and wiki
  links. Other Markdown constructs open in exact Source view so their text is
  preserved; they cannot be edited in Rich view.
- Wiki Peek currently shows text descriptions. Rich media previews are not
  available there.
- Dated map path and region geometry switches at its authored date. It does not
  interpolate between shapes.

Please report bugs with the package version, Windows version and steps needed
to reproduce them.
