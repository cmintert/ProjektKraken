# ProjektKraken 0.21.0 beta 1

Windows x64 beta candidate. This version adds linked Event timing, dependency
trails, activity workspaces and historical World Context since 0.20.1-beta1.

These notes describe the prepared source candidate. Check the
[Releases page](https://github.com/cmintert/ProjektKraken/releases) for published
packages. Publication requires verification of the committed candidate and the
actual Windows package.

## Changes since 0.20.1-beta1

- Event starts and independent ends can follow another Event's start or end,
  using signed day or whole calendar-month/year offsets. Review dependent date
  changes before applying a cascade as one undoable operation. Timing drafts
  wait for **Save Changes** while other fields can autosave separately.
- Timeline dependency strands show the Follow Event network. Choose All,
  Selected, Show dependency trail or Off; trails include branches and merges.
  Chronological lanes use measured event bounds, and dependency wires route
  around intervening event clusters.
- Map feature and group presence can follow named Event starts or ends, with
  offsets and preserved date uncertainty. Dated path and region shapes still
  switch at their authored dates without interpolation.
- Activity workspaces provide Overview, Writing, Chronology, Cartography,
  Connections and Research arrangements. Each retains its layout while keeping
  live writing, selection and viewed time. Custom workspaces remain available.
- One searchable Settings Center separates application and world configuration.
  World policies travel with the world; application preferences remain local.
- Entity World Context supports At playhead, History to playhead and All history.
  Fact rows distinguish timing, sources, possible changes and weaker associations.
  Load more saved direct connections, including custom names and either direction,
  without expanding the separately bounded AI input.
- Keyboard navigation keeps Tab within a panel and uses F6 / Shift+F6 to move
  between visible regions. Inspector layout and resize stability are improved.
- The user manual includes task guides, the Northwatch tutorial and conceptual
  explanations. Offline Help and control inspection cover the updated workflows.

The repository
[changelog](https://github.com/cmintert/ProjektKraken/blob/main/CHANGELOG.md)
contains the detailed history.

## World upgrade and recovery

This release upgrades worlds to **schema 4**, allowing Event coordinates to
remain unresolved without inventing dates. Migration preserves authored records
and command history and creates an upgrade recovery bundle.

Back up your complete world folder before opening it in this version. Retain
the original backup and the reported recovery bundle. **Older application
versions reject a schema-4 world**; returning to the previous application
requires a compatible pre-upgrade copy. Database recovery does not replace a
backup of your map images and other asset files.

See [world portability and recovery](../user/portability-and-recovery.md) for
the storage distinctions and recovery guidance.

## Install and verify

Once published, download `ProjektKraken-0.21.0-beta1-windows-x64.zip` and its
matching `.zip.sha256` file. In PowerShell, run:

```powershell
Get-FileHash .\ProjektKraken-0.21.0-beta1-windows-x64.zip -Algorithm SHA256
```

Compare the reported hash with the checksum file. Extract the complete ZIP into
an ordinary user folder, then run `ProjektKraken\ProjektKraken.exe`. Keep
`_internal` beside the executable. Python is not required. The application is
unsigned; Windows may ask you to confirm that you want to run it.

When updating, install the complete new application folder. Do not replace only
the executable. See the [installation guide](../user/getting-started.md#install-and-launch).

## Known limitations

- Windows x64 is the packaged platform for this beta.
- Relation vocabulary and forward/reverse wording remain follow-up work.
- Rich wiki editing supports paragraphs, headings 1–3, bold, italic and wiki
  links. Other Markdown constructs remain editable in exact Source view.
- Wiki Peek shows text descriptions without rich media previews.
- Dated map geometry switches between saved shapes; it does not morph.
- Unresolved timing does not establish an exact date. Imported broken references
  need correction; unsupported timing metadata is preserved with its timing
  controls unavailable. Resolve timing references before deleting their source
  Event or removing a referenced end.

Please report bugs with the package version, Windows version and steps needed
to reproduce them.
