# ProjektKraken 0.19.7 beta 1

Windows x64 beta package. This release includes temporal map and timeline
authoring, event chronology rules, and wiki editor improvements since
0.19.6-beta1.

## Install and verify

Download `ProjektKraken-0.19.7-beta1-windows-x64.zip` and its matching
`.zip.sha256` file. In PowerShell, run:

```powershell
Get-FileHash .\ProjektKraken-0.19.7-beta1-windows-x64.zip -Algorithm SHA256
```

Compare the reported hash with the value in the `.sha256` file. Extract the
complete ZIP into a normal user folder, then run
`ProjektKraken\ProjektKraken.exe`. Keep `_internal` beside the executable.
The application is unsigned; Windows may ask you to confirm that you want to
run it.

For an update, keep a backup of your existing `worlds` folder and install
the complete new application folder. Do not replace only the executable.

## Known limitations

- Windows x64 is the packaged and tested platform for this beta.
- Rich wiki editing supports paragraphs, headings 1–3, bold, italic, and
  wiki links. Other Markdown constructs open in exact Source view so their
  text is preserved; they cannot be edited in Rich view.
- Wiki Peek currently shows text descriptions. Rich media previews are not
  available there.
- Dated map path and region geometry switches at its authored date. It does
  not interpolate between shapes.

Please report bugs with the package version, Windows version, and the steps
needed to reproduce them.
