# ProjektKraken 0.22.0 beta 1

This Windows x64 beta adds connected detail maps, recurring Events, and a
date-first Event editor. It also adds visual Markdown table editing and optional
local MCP sharing.

## Changes since 0.21.0-beta1

- Register detail maps with parent maps and adjust their placement against the
  parent before applying it. Connected maps can show dated points, paths, and
  regions from other maps in the hierarchy. Open the source map to edit a
  projected feature.
- Trace shared region borders, cut one region from another, and smooth paths
  while keeping both endpoints fixed. Areas cut from a region can form holes.
- Set an Event to repeat by calendar units. The Timeline shows occurrences from
  the original Event and keeps them linked to its authored timing.
- Edit an Event's date and description in Overview. Open **Timing options**
  for sources, offsets, end dates, and recurrence. **Character Lifespans** in
  Analysis shows the age, range, or estimate supported by the recorded dates
  and links to the source Events.
- Edit GitHub Flavored Markdown tables in the visual editor, or switch to
  **Source** for direct Markdown editing. Paste keeps supported structure and
  wiki links.
- Enable optional, session-scoped MCP sharing to let a local client read the
  active world. Sharing can be turned off in the application.

See the [changelog](https://github.com/cmintert/ProjektKraken/blob/0.22.0-beta1/CHANGELOG.md#0220)
for the detailed history.

## World upgrade and recovery

Back up your complete world folder before opening it in this version. Kraken
upgrades older world databases to **schema 8**, which supports region holes and
updated command-history storage. Keep your original backup and the recovery
bundle reported during the upgrade. To reopen the world in 0.21.0 or earlier,
use a compatible pre-upgrade copy. The recovery bundle does not replace a backup
of your map images and other assets.

## Install and verify

Download `ProjektKraken-0.22.0-beta1-windows-x64.zip` and its matching
`.zip.sha256` file from the GitHub release. In PowerShell, run the following.

```powershell
Get-FileHash .\ProjektKraken-0.22.0-beta1-windows-x64.zip -Algorithm SHA256
```

Compare the reported hash with the checksum file. Extract the complete ZIP into
an ordinary user folder, then run `ProjektKraken\ProjektKraken.exe`. Keep
`_internal` beside the executable. Windows may prompt you before running the
unsigned application.

When updating, install the complete new application folder. For more detail,
see the [installation guide](https://github.com/cmintert/ProjektKraken/blob/0.22.0-beta1/docs/user/getting-started.md#install-and-launch).

## Known limitations

- Windows x64 is the packaged platform for this beta.
- Dated paths and regions switch between their saved shapes at the authored
  dates. Positions along a trajectory follow the trajectory's own timing.
- Source Events with unresolved timing can leave a calculated age unavailable.

Please report bugs with the package version, Windows version, and steps to
reproduce them.
