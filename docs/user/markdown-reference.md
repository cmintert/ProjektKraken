# Kraken Markdown profile

Event and Entity descriptions use Markdown source stored in the world database.
The editor, desktop Longform, published Longform and document export share profile
version 1. Parsing and URL recognition run locally.

## Syntax and reading support

| Feature | Profile version 1 |
| --- | --- |
| CommonMark paragraphs, headings, emphasis, links, images, quotes, lists and code | Parsed using markdown-it-py 4.2.0 |
| Single newline | Displayed as a visible line break |
| Tables | GFM tables, including empty cells and column alignment |
| Strikethrough | Double tildes, such as `~~former name~~` |
| Automatic links | Recognized URLs become links when the destination permits navigation |
| Wikilinks | `[[Name]]`, `[[Name\|Label]]` and `[[id:UUID\|Label]]` |
| Compatibility extensions | Footnotes, definition lists and abbreviation definitions |
| Task lists | Ordinary lists retaining the literal `[ ]` or `[x]` text |
| Callouts, embeds and highlights | Source retained for later feature support |
| YAML frontmatter | Interpreted by note import/export; description text follows the Markdown grammar |

The foundation is CommonMark 0.31.2 with the explicit extensions above. Visible
single newlines are a Kraken rendering choice. The upstream parser matches 649
of the standard's 652 reference HTML strings exactly. The remaining three produce
equivalent empty blockquotes with different HTML whitespace.

Use an escaped pipe in an aliased wikilink inside a portable table cell, such as
`[[Aldric\|the ruler]]`. Existing cells with unescaped wikilink alias pipes retain
their reading behavior. This compatibility handling affects the parsing buffer;
the stored source stays intact.

GFM tables contain inline cell content. Merged cells and multiline block content
require HTML source and remain in Source view. For visual table authoring, see
{ref}`Create and edit a table <help-inspect-writing-tables>`.

## Editing and preservation

Rich editing supports the existing conservative vocabulary of paragraphs,
headings through level three, bold, italic, wikilinks and GFM tables. Cells also
retain strikethrough, code spans and ordinary Markdown links. Other structures remain
editable in Source view, with a visible preservation notice.
Source spellings outside the retained cursor mapper's vocabulary also use Source
view so that selections continue to address the original text.

Opening, rendering, switching views and saving an unedited description preserve
its source exactly, including entity spelling and blank-line spacing. Rich edits
serialize supported structures while preserving text, formatting and link
targets. Undo restores the original source when it returns to the original
projection. Source edits retain the text the writer supplies.

Wikilinks inside code spans, fenced code, escaped examples, HTML attributes and
HTML code elements remain literal. Internal links retain stable targets while
display labels can differ. Markdown references and asserted world relationships
remain separate parts of the world model.

## HTML and destination behavior

Basic HTML formatting and table structure are rendered through a shared sanitizer.
Allowed table attributes include alignment and positive row/column spans.
Executable elements, event handlers and unsupported styling are removed from
rendered output. The original source is retained.

Published Longform permits HTTP, HTTPS, mail and in-document fragment links.
Its wikilink navigation metadata is generated by the parser; authored HTML cannot
create it. Inline images remain subject to each destination's existing asset
policy. Document export checks local images against the selected world folder.

Qt previews and document formats have their own presentation adapters. DOCX
export retains strikethrough and table column alignment. Sanitization, typography
and navigation attributes can differ between destinations while sharing syntax.

## Implementation and distribution

The runtime uses markdown-it-py 4.2.0, linkify-it-py 2.2.0 and mdit-py-plugins 0.7.0.
Footnote and definition-list plugins preserve existing reading behavior; Kraken's
own rules handle identity-bearing wikilinks and legacy abbreviations.

The Windows package includes the installed copyright and licence texts for these
libraries and mdurl in `_internal/third_party_licenses/`. Its smoke test exercises
the parser, plugins, URL recognition and notice files.
