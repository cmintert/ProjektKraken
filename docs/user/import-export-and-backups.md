# Import, Export, and Backups

## Import items

Use **File → Import Item…** to import a supported JSON file. ProjektKraken
normalizes the input and shows a preview before applying it.

Use **File → Import Pasted JSON…** when the source is already on the clipboard.
Check the preview for duplicates, unresolved references, and unexpected types.

Create a backup before importing a large or unfamiliar data set.

## Export

- **File → Export → Export Longform to Markdown…** creates one narrative file.
- **File → Export → Export as Obsidian Vault…** creates linked Markdown files.
- The Explorer context menu can export a selected item to Obsidian Markdown.
- Command-line tools provide additional JSON-oriented automation.

## Back up a world

Open **File → Backup & Restore** to:

- create a manual backup;
- restore a backup;
- open the backup location;
- configure automatic backup behaviour.

Restoring replaces the active world state and is not an ordinary undoable
action. Keep an additional copy when the current state may still be useful.
