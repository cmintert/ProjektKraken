# Review a documentation change

Use this form with the [authoring standard](documentation.md). Copy the fields
into the change's indexed evidence page. Mark unavailable evidence **Pending**
or **Not tested**; use **Not applicable** only with a reason.

For each changed procedure, record its starting state, preferred route,
save/apply action, expected result, consequences and recovery. Trace the
operation beyond its button label. Distinguish source inspection, automated
execution, native observation and participant self-report.

## Integration and rendered review

- [ ] Inspection checker, offline Help build and schema check pass.
- [ ] Strict Sphinx passes and every new page is in navigation.
- [ ] Existing IDs, meanings, anchors, excerpts and related links are retained.
- [ ] Generated pages, tables, images/alternative text and links were inspected.
- [ ] Search reaches the intended task/reference destination.
- [ ] Offline Help is readable at normal and narrow sizes in supported themes.
- [ ] F1, pointer/focus explanations and Inspect control resolve correctly.
- [ ] Help preserves drafts, caret/selection, playhead, working copies, local
  Escape behavior, focus restoration and modal ownership.

Record command, result, date and artifact location for automated checks. For
rendered checks, record page, viewport/theme, review method and corrections.
Offscreen tests do not demonstrate native display or independent human review.
