# Configuration Reference

## Launch options

| Option | Effect |
| --- | --- |
| `--reset-settings` | Clears saved interface preferences and active-world selection |
| `--set-default-layout` | Captures the closing layout as the factory default |

## Semantic search environment variables

| Variable | Purpose |
| --- | --- |
| `EMBED_PROVIDER` | Selects the embedding provider |
| `LMSTUDIO_EMBED_URL` | Overrides the LM Studio embedding endpoint for CLI use |
| `LMSTUDIO_MODEL` | Selects an embedding model for CLI use |
| `LMSTUDIO_API_KEY` | Supplies an optional local-server API key |
| `PK_SEMANTIC_COMPLETION_ENABLE_EMBEDDING` | Enables embedding-backed semantic completion |

Desktop AI settings are normally configured per world through
**Settings → AI Search Index and Settings…**.
